# 人脸识别打卡系统 v1.0

基于 **OpenCV (LBPH)** 算法的人脸识别考勤系统，通过摄像头实时识别人脸完成打卡签到，替代传统指纹/刷卡考勤方式，提升考勤效率。

## 功能概览

| 功能 | 说明 |
|------|------|
| 📷 人脸识别打卡 | 摄像头实时检测人脸，自动识别员工身份并记录打卡时间 |
| 👤 员工注册 | 采集员工多角度人脸样本，建立人脸数据库 |
| 🎯 模型训练 | 使用 LBPH 算法训练分类模型，支持增量更新 |
| 📋 打卡记录 | 按日查看和查询历史打卡记录 |
| 👥 员工管理 | 查看已注册员工列表及样本数量 |

## 技术原理

### LBPH (Local Binary Patterns Histograms)

采用 OpenCV 内置的 LBPH 人脸识别算法：

1. **人脸检测**: Haar Cascade 分类器检测正脸和侧脸
2. **特征提取**: LBP 算子提取局部纹理特征，生成直方图
3. **识别匹配**: 计算输入图像直方图与训练集直方图的相似度（置信度）
4. **阈值判定**: 置信度 < 80 判定为匹配成功

### 技术栈

- **Python 3.9+** — 开发语言
- **OpenCV 4.8+** (opencv-contrib-python) — 人脸检测与识别
- **NumPy** — 图像数据处理
- **CSV** — 打卡记录持久化

## 安装与运行

### 1. 安装依赖

```bash
pip install opencv-contrib-python numpy
```

### 2. 注册员工

```bash
python face_register.py
```

- 输入员工姓名
- 正对摄像头，系统自动采集 60 张不同角度的人脸样本

### 3. 训练模型

```bash
python train_model.py
```

- 基于采集的样本训练 LBPH 识别模型

### 4. 启动打卡

```bash
# 方式一：菜单导航
python main.py

# 方式二：直接启动打卡
python attendance.py
```

### 使用流程

```
注册员工 → 训练模型 → 启动打卡 → 自动识别 → 生成记录
```

## 操作说明

### 打卡界面快捷键

| 按键 | 功能 |
|------|------|
| `ESC` | 退出打卡 |
| `R` | 查看今日打卡记录 |
| `T` | 重新训练模型（添加新员工后使用） |

### 记录格式

每日打卡记录以 CSV 格式保存在 `attendance_logs/` 目录：

```csv
姓名,日期,时间
张三,2026-01-01,09:00:23
李四,2026-01-01,09:01:15
```

## 系统特点

- **离线运行**: 完全本地处理，无需网络连接，保护员工隐私
- **防重复打卡**: 同一员工每天仅记录首次打卡，避免重复
- **抗干扰**: LBPH 算法对光照变化有一定鲁棒性
- **轻量级**: 无需 GPU，普通 PC 即可流畅运行
- **可扩展**: 支持随时添加新员工，增量训练模型

## 性能参考

|------|------|
| 人脸检测帧率 | ~15-20 FPS (720p) |
| 识别准确率 | ~90%+ (正面光照充足) |
| 单员工注册时间 | ~30 秒 |
| 模型训练时间 | < 5 秒 (10人以内) |

## 目录结构说明

| 文件/目录 | 说明 |
|-----------|------|
| `main.py` | 系统主菜单，提供图形化操作导航 |
| `face_register.py` | 调用摄像头采集人脸样本，保存至 `data/faces/` |
| `train_model.py` | 读取样本数据，训练 LBPH 模型，输出 `trainer.yml` |
| `attendance.py` | 实时识别打卡 + 记录查看/查询功能 |
| `utils.py` | 公共函数：文件操作、日志写入、UI 辅助绘制 |
| `data/` | 存放训练数据和模型（自动创建） |
| `attendance_logs/` | 存放每日打卡 CSV 记录（自动创建） |

## 注意事项

1. **光照条件**: 建议在光照均匀的环境下使用，避免强背光
2. **正面采集**: 注册时请正对摄像头，缓慢转动头部采集多角度样本
3. **添加新员工**: 新员工注册后需重新训练模型（按 `T` 键或运行 `train_model.py`）
4. **摄像头权限**: 确保系统已授予摄像头访问权限
